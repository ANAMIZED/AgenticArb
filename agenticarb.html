Why it isn't a simple funding bot

  • Regime-aware funding persistence predictor — will the carry actually stick around?
  • Asset-specific empirical gap distributions instead of one-size-fits-all assumptions.
  • L2 order-book impact + dynamic capacity model — knows when a trade is too big for the book.
  • ADL rank heuristic to avoid being first in line for auto-deleveraging.
  • Formal risk gates as pure functions — every trade must pass, every time.
  • Continuous adversarial self-play: the system red-teams itself before markets do.
  • Hybrid cognition: LangGraph agents wake only on anomalies or meta-review — the critical path stays deterministic.

Quick start

git clone https://github.com/ANAMIZED/agenticarb.git
cd agenticarb
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"

# full system verification — must exit 0
python -m agenticarb.cli verify

Docker alternative

# no local Python deps needed
docker compose build
docker compose run --rm agenticarb

Project layout

src/agenticarb/quant/persistence · gaps · impact/capacity · ADL · risk gates
src/agenticarb/agents/graph.py — LangGraph multi-agent cognitive layer
src/agenticarb/execution/dual-leg executor + Hyperliquid client
src/agenticarb/simulation/high-fidelity engine + adversarial episodes
src/agenticarb/security/agent wallet + audit log
tests/unit + end-to-end
configs/default.yaml — risk limits, thresholds, SLA, session keys
rust/future critical path
Dockerfile · docker-compose.yml · Makefileone-command build & verify
⚠ LIVE TRADING NOTES Paper/sim is the safe default. Going live requires the Hyperliquid Python SDK, a non-custodial agent wallet with no withdrawal rights, session keys enforced by AgentWalletGuard, and an explicit MODE=live. Never grant withdrawal rights to agent wallets.
